# Projeto 01 — GDrive Automóveis

Projeto demonstrativo desenvolvido para o portfólio da GStudios06.

## Funcionalidades
- Hero comercial
- Catálogo de veículos
- Busca por marca/modelo
- Filtro por marca, câmbio e preço
- CTA individual para WhatsApp
- Layout responsivo

## Observação
Veículos, valores e números exibidos são fictícios e servem apenas para demonstração do portfólio.
