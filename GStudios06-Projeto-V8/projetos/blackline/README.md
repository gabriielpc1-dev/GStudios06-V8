# GStudios06 — Projeto 02: BlackLine Estética Automotiva

Projeto demonstrativo de uma landing page comercial para uma empresa fictícia de estética automotiva.

## Objetivo
Demonstrar a capacidade da GStudios06 de criar sites comerciais modernos, responsivos e focados em conversão.

## Seções
- Hero
- Serviços
- Resultados/Galeria
- Pacotes
- Sobre a empresa
- CTA para WhatsApp
- Layout responsivo

## Observação
Este é um projeto demonstrativo. Nome, preços, avaliações e informações da empresa são fictícios.

As imagens são carregadas de URLs externas e podem ser substituídas por fotos próprias/licenciadas em um projeto real.
